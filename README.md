# Beginner Git & GitHub Handbook

A quick-reference guide designed to help student developers understand core Git commands and collaborative GitHub workflows. It solves the confusion of managing code versions on a team by providing clear, step-by-step examples for branching, pull requests, and resolving conflicts.

## Git Best Practices
Always run `git pull origin main` before creating a new feature branch so you start from the latest code.
Summarize what changed and why in a short, descriptive message.
Never commit directly to `main`; use Pull Requests so changes can be reviewed first.
